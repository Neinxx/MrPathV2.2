## 总览
- 聚焦噪声遮罩体系与路肩柏林噪声，统一CPU/GPU评估路径，降低逐样本分配与三角函数开销，引入依赖注入与可复用服务，实现提前返回与单一职责。

## 痛点定位
- 逐样本分配与三角函数：`NoiseMask.cs:65-77`、`ShoulderPerlinNoiseMask.cs:97-116`、旋转在`ShoulderPerlinNoiseMask.cs:107-111`。
- fBm循环成本：`NoiseMask.cs:80-91`、`ShoulderPerlinNoiseMask.cs:125-133`。
- CPU图集构建串行开销：`MaskAtlasGenerator.cs:313-331`。
- 重复阈值矫正：`NoiseMask.cs:42-54`、`ShoulderPerlinNoiseMask.cs:53-67` 与评估内部再矫正。

## 架构重构
- 抽象接口
  - `IMaskEvaluator`：纯评估接口，不依赖具体`ScriptableObject`，输入为参数快照。
  - `INoiseSampler`：统一噪声取样（CPU使用LUT），与GPU侧保持一致。
  - `IFbmEvaluator`：负责fBm叠加，接受`octaves/lacunarity/gain`与基础采样委托。
- 依赖注入
  - 由工厂将`BlendMaskBase`的静态数据打包为“参数DTO”，注入到`IMaskEvaluator`具体实现（噪声、路肩噪声、路肩形状）。
  - `MaskAtlasGenerator`在CPU回退时仅依赖接口，不直接依赖具体遮罩类。
- 职责拆分
  - `ShoulderPerlinNoise`拆分为“路肩形状评估”和“噪声评估”两模块；合成器按权重乘法输出。
  - 将阈值排序逻辑移至`OnValidate/工厂`，评估阶段不再二次排序。

## 性能优化
- 预计算缓存
  - 旋转`cos/sin`与旋转零标记、统一缩放`scaleXY`、`seedOffset`在`OnValidate/工厂`预先计算并缓存到DTO。
  - fBm中常量项统一预处理（`octaves`、`lacunarity`、`gain`边界）。
- 去分配与数学加速
  - 用标量流水线替代`new Vector2`，仅对`ruv.x/ruv.y`进行就地计算；减少临时结构体。
  - 在CPU路径与作业中采用`Unity.Mathematics`的`math`函数（项目已有依赖），结合Burst提高吞吐。
- CPU图集并行化
  - 将`BuildAtlasCpu`改为`IJobParallelFor`按行或按层×行并行，使用`NativeArray<byte>`与`Texture2D.SetPixelData`写回，避免`Color32[]`转换开销。
- 提前返回
  - 路肩禁用或路肩形状为零时立刻返回：`ShoulderPerlinNoiseMask.cs:71-73,93`已具备，进一步确保在噪声评估前返回。

## 具体改造清单
- 数据DTO
  - 新增`NoiseParamsDto`、`ShoulderParamsDto`用于评估缓存；由工厂从`BlendMaskBase`派生实例构建。
- 评估器实现
  - `NoiseMaskEvaluator`：基于DTO与`INoiseSampler`进行旋转、偏移、fBm与平滑。
  - `ShoulderShapeEvaluator`：计算两侧路肩权重，并支持非对称软化。
  - `ShoulderNoiseCompositeEvaluator`：组合两者输出并统一整体缩放/阈值。
- `MaskAtlasGenerator` CPU回退
  - 将内层双循环移入Burst Job；每个`py`预先计算`v`，`px`循环仅做水平方向。
  - 使用`Texture2D.SetPixelData<byte>(0)`写回，减少托管分配与拷贝。
- 阈值与平滑
  - 将非对称阈值排序在`OnValidate`完成；`Evaluate`中直接使用已排序的`low/high`，移除重复排序分支。

```csharp
public readonly struct NoiseParamsDto
{
    public readonly float seed;
    public readonly float scaleX;
    public readonly float scaleY;
    public readonly float cos;
    public readonly float sin;
    public readonly int octaves;
    public readonly float lacunarity;
    public readonly float gain;
    public readonly float edgeLow;
    public readonly float edgeHigh;
    public readonly bool asymmetric;
    public readonly float overall;
    public readonly float smooth;
    public readonly float seedX;
    public readonly float seedY;
    public NoiseParamsDto(float seed, Vector2 scale, float rotRad, int oct, float lac, float g, float low, float high, bool asym, float overall, float smooth)
    {
        this.seed = seed;
        scaleX = scale.x;
        scaleY = scale.y;
        cos = math.cos(rotRad);
        sin = math.sin(rotRad);
        octaves = math.max(1, oct);
        lacunarity = math.max(1f, lac);
        gain = math.clamp(g, 0f, 1f);
        edgeLow = math.clamp(low, 0f, 1f);
        edgeHigh = math.clamp(high, 0f, 1f);
        asymmetric = asym;
        this.overall = overall;
        this.smooth = smooth;
        var sx = math.abs(math.sin(seed * 12.9898f) * 43758.5453f);
        var sy = math.abs(math.sin(seed * 78.233f) * 12345.678f);
        seedX = sx - math.floor(sx);
        seedY = sy - math.floor(sy);
    }
}

public static float EvaluateNoise(in NoiseParamsDto p, float u, float v)
{
    var x = u * p.scaleX;
    var y = v * p.scaleY;
    var rx = x * p.cos - y * p.sin + p.seedX;
    var ry = x * p.sin + y * p.cos + p.seedY;
    var amp = 1f;
    var freq = 1f;
    var sum = 0f;
    var norm = 0f;
    for (var i = 0; i < p.octaves; i++)
    {
        var s = NoiseLutProvider.Sample01(rx * freq, ry * freq);
        sum += s * amp;
        norm += amp;
        freq *= p.lacunarity;
        amp *= p.gain;
    }
    var n = norm > 1e-5f ? sum / norm : 0f;
    var v0 = math.clamp(n, 0f, 1f);
    var v1 = p.overall * v0;
    if (p.asymmetric)
    {
        if (v1 <= p.edgeLow) return 0f;
        if (v1 >= p.edgeHigh) return 1f;
        var t = (v1 - p.edgeLow) / math.max(1e-6f, p.edgeHigh - p.edgeLow);
        var sm = t * t * (3f - 2f * t);
        return math.clamp(sm, 0f, 1f);
    }
    return ApplySmoothingRaw(v1, p.smooth);
}

public static float EvaluateShoulder(float distFromCenter, float center, float stripeHalf, float falloff)
{
    var d = math.abs(distFromCenter - center);
    if (falloff <= 1e-6f) return d <= stripeHalf ? 1f : 0f;
    var t = 1f - math.saturate((d - stripeHalf) / falloff);
    return math.saturate(t);
}
```

```csharp
[BurstCompile]
public struct BuildMaskAtlasJob : IJobParallelFor
{
    [WriteOnly] public NativeArray<byte> outR;
    public int width;
    public int pathSamples;
    public float worldWidth;
    public float pathLength;
    public NoiseParamsDto noise;
    public ShoulderParamsDto shoulder;
    public float maskThreshold;
    public void Execute(int index)
    {
        var layerIndex = index / pathSamples;
        var py = index % pathSamples;
        var progress = (float)py / math.max(1, pathSamples - 1);
        var v = TransformPathPosition(progress, pathLength);
        for (var px = 0; px < width; px++)
        {
            var across01 = (float)px / math.max(1, width - 1);
            var across = across01 * 2f - 1f;
            var u = TransformPosition(across, worldWidth, pathLength);
            var shape = ShoulderShape(across, worldWidth, shoulder);
            var val = shape <= 0f ? 0f : shape * EvaluateNoise(noise, u, v);
            var shaped = maskThreshold <= 0f ? val : math.saturate((val - maskThreshold) / math.max(1e-5f, 1f - maskThreshold));
            outR[px + index * width] = (byte)(shaped * 255f);
        }
    }
}
```
