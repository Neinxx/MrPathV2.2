# 目标
- 支持噪声以“剔除（alpha clip）”与“Alpha 混合（blend）”两种方式裁剪/混合 `TerrainLayer`，形成可堆叠的 Photoshop 风格层效果。
- 保证所见即所得（Editor 预览与实际写入同源）、数据同源（CPU/GPU使用同一参数打包与评估逻辑）。
- 提升 `LayerMask` 选择窗口中噪声 ScriptableObject（SO）的创建与管理便利性。
- 所有新增 UI 采用 UIToolkit 的 `UXML`/`USS`。

## 架构概览
- **数据层（SO）**：统一“遮罩图谱”和“层堆栈”描述；现有 `StylizedRoadRecipe` 继续作为配方入口，内部改为 `LayerStack` 结构，包含若干 `LayerEntry`（TerrainLayer + BlendMode + MaskSlot + 权重/阈值等）。
- **评估层（CPU/GPU）**：抽象 `IMaskEvaluator` 与 `IMaskParameterPack`，所有噪声遮罩继承 `BlendMaskBase`，通过同一 `ParameterPack` 写入 Compute/Shader，CPU侧使用同样参数进行评估，避免分歧。
- **渲染/写入层**：
  - 预览：`PathPreviewSplatMulti.shader` 和 `MaskAtlas.compute` 统一从 `ParameterPack` 读取，按层顺序与 BlendMode 渲染。
  - 写入地形：`PaintSplatmapCompute.compute` 与 `PaintSplatmapJob.cs` 使用同一阈值/混合策略；支持 AlphaClip 与 AlphaBlend 两模式。
- **编辑器层（UIToolkit）**：集中化的 `LayerStackEditor`（UXML/USS），并在 `LayerMaskSelectWindow` 增加“快速创建噪声SO”“预设库”“内联参数编辑”。

## 数据模型调整
- **LayerStackSO**：新建或扩展现有 `StylizedRoadRecipe` 的内部结构为 `LayerStack`；字段：
  - `List<LayerEntry>`：顺序即叠加顺序；每项包含：
    - `TerrainLayerRef`（引用或GUID）
    - `BlendMode`（Normal、Multiply、Overlay、Add、AlphaClip、AlphaBlend 等可扩展枚举）
    - `MaskSlot`（`BlendMaskBase` 派生SO或组合SO `ComposedMaskSO`）
    - `Opacity`（0-1）、`AlphaClipThreshold`（常量集中管理，避免魔法数字）、`Enabled`
- **Mask 组合**：保留并规范 `ComposedMaskSO` 与现有变体SO（Perlin/Worley/Stripe 等），统一实现 `IMaskEvaluator` 与 `IMaskParameterPack`。
- **参数打包**：集中 `MaskParameterPack`（结构体），所有遮罩将其写入 ComputeBuffer/Shader 常量；CPU评估同包解析。
- **依赖注入**：在 `CpuTerrainPainter`/`PaintSplatmapJob`/预览管线中以接口注入 `IMaskEvaluator` 与 `ILayerBlender`，避免直接依赖具体类。

## 混合与裁剪策略
- **AlphaClip**：对每层在遮罩域内执行 `alpha >= clipThreshold ? write : discard`；在写入阶段对应 `AlphaClipThreshold` 常量，预览与写入同源。
- **AlphaBlend**：在遮罩域内对 `TerrainLayer` 的权重执行 `w = lerp(w, target, opacity * mask)`；BlendMode 决定 `target` 的合成（Normal/Multiply/Overlay 等）。
- **顺序与归一化**：按 `LayerEntry` 顺序进行合成，末尾归一化权重；对“非配方层”可选择缩放保留或清零（沿用现有管线）。

## 所见即所得与同源保证
- **单源参数**：`MaskParameterPack` 作为唯一参数来源；Editor 预览与地形写入共享。
- **统一评估函数**：在公共 `MaskEvaluate.hlsl` 中定义评估函数，Compute/Shader 引用同一 HLSL；CPU 端 C# 以同名公式实现，保持数值一致。
- **阈值管理**：所有阈值（如 clip、smooth、edge band）集中在 `MaskConstants`，禁止硬编码魔法数字。

## 编辑器 UI（UXML/USS）
- **LayerStackEditor（新窗口/或嵌入 `StylizedRoadRecipeEditor`）**：
  - UXML：层列表（可重排）、每层行包含：TerrainLayer选择器、BlendMode下拉、Opacity滑条、启用开关、Mask选择/编辑按钮、阈值字段。
  - USS：复用 `ReorderableStyles.uss` 与自定义主题；交互联动即时刷新预览。
- **LayerMaskSelectWindow 增强**：
  - 顶部“新建噪声SO”按钮与预设下拉（Perlin/Worley/Stripe/Texture 等），一键创建并命名，保存至指定文件夹（路径可配置）。
  - 右侧“内联参数面板”，直接编辑所选SO参数；更改后实时写回并刷新预览。
  - 搜索/过滤、收藏与最近使用列表；支持拖放到 `LayerEntry` 的 `MaskSlot`。
- **PathProfile/StylizedRoadRecipe Inspector**：
  - 嵌入 `LayerStackEditor` 的简版；提供预览开关与快速跳转到完整窗口。

## 管线改造点
- **Compute 侧**：在 `PaintSplatmapCompute.compute` 中接入 `BlendMode` 与 `AlphaClipThreshold` 参数；引入 `MaskEvaluate.hlsl`；确保 `_MaskAtlas` 采样与直接评估路径一致。
- **CPU 侧**：`PaintSplatmapJob.cs` 添加 `ILayerBlender` 策略类，早返回与单一职责，减少分支复杂度；参数使用 `MaskParameterPack`。
- **预览 侧**：`PathPreviewSplatMulti.shader` 读取同包参数，渲染与写入策略一致；可切换显示单层或堆叠结果。

## 迁移与兼容
- 保留现有 `StylizedRoadRecipe` 资产结构，新增 `LayerStack` 字段；提供迁移器将旧 `RoadLayer` 映射到新 `LayerEntry`。
- 旧遮罩SO仍可用；若缺少 `IMaskParameterPack` 实现，提供适配器。

## 性能与优化
- 参数按块更新（Dirty 标记），避免每帧重建Buffer；遮罩图谱（Atlas）仅在参数变更时重算。
- 大地图写入分区批处理；GPU/CPU路径一致性优先，在高分辨率时优先GPU。
- 早返回：在评估与混合函数内对 `opacity == 0`、`mask == 0` 等直接跳过。

## 测试与验证
- 单元测试：CPU评估与GPU结果对齐（采样同位置），阈值边界与多 BlendMode 结果比对。
- 交互测试：编辑器参数变更触发预览刷新，创建SO流程可用性测试。
- 资产兼容：旧项目加载无异常，迁移后结果一致。

## 交付物
- 数据模型与接口（`LayerEntry`、`LayerStack`、`IMaskEvaluator`、`ILayerBlender`、`MaskParameterPack`、`MaskConstants`）。
- 改造的 Compute/HLSL/Shader 预览引用；统一评估函数。
- 编辑器 UXML/USS 与窗口逻辑（`LayerStackEditor`、增强 `LayerMaskSelectWindow`）。
- 迁移工具与测试用例。
