计算着色器已接入 BlendMode 权重混合

已将 PaintSplatmapCompute.compute 接入统一的 BlendWeight 函数， 按 Normal / Multiply / Add / Overlay / Screen / Lerp / Additive 模式对通道权重进行混合。

Unity 内验证步骤

  1. 在 Project 面板右键 Editor/Resources/PaintSplatmapCompute.compute，执行 Reimport。
  2. 打开预览窗口或场景中使用路径工具的预览材质，确保材质或代码绑定：
    • _UseSplatWeights 设为 1（优先从 GPU 权重采样）。
    • _SplatWeights 的 RenderTexture 已正确绑定到预览材质。
    • LayerParamsBuffer 的 BlendMode、Opacity、TerrainLayerSplatIndex 与 C# 设置一致。
  3. 在道路上拖动或切换不同 BlendMode：
    • Normal：当前层权重将覆盖目标通道（按不透明度与遮罩）。
    • Add / Additive：权重与当前值相加并夹取至 [0,1]。
    • Multiply：与当前值相乘，适合压暗/压低权重。
    • Overlay / Screen / Lerp：按库函数对权重进行相应混合。
  4. 观察 通道归一化：若四通道和 > 1，会按比例从非选中通道回收超额，避免整体泛灰。

注意事项

  • 确保 TerrainLayerSplatIndex 与 terrainData.terrainLayers 的索引一致。
  • _SplatWeights 必须是 2DArray 且 UNorm 格式，支持读写。
  • 若开启 MaskAtlas，请确认遮罩采样使用路径进度 progress 与横向位置一致。

如果以上检查都通过，GPU 预览与实际绘制的权重表现应与 CPU 一致。
