MrPathV2 预览与性能更改概览

CPU 绘制优化

  • 改为 局部 alphamap 读写，避免整张读取与写回。
  • PaintSplatmapJob 索引改为 局部数组布局（index * layerCount）。
  • 减少数组复制与 TerrainData.SetAlphamaps 的写回开销。

仅绘制道路覆盖区域（最新）

  • CPU 路径：像素级 IsInside 裁剪，未触及道路像素不做归一化与写入。
  • GPU 路径：计算着色器以 coverageMin/Max + 道路遮罩限定混合范围。

最优算法自适应（最新）

  • 新增 gpuAutoSwitchThreshold：覆盖面积超过阈值且支持 Compute 时自动切换 GPU。
  • 小面积沿用 CPU，两阶段 Job，避免不必要的 GPU 读写与同步。

预览可见性

  • 取消全局渲染的跳过逻辑：编辑点曲线与 Transform 时 不再隐藏 预览。
  • 文件：Editor/Preview/MultiPathPreviewRenderer.cs 中 ShouldSkipCreatorRendering 始终返回 false。

建议验证

  • Unity Profiler 中观察 CPU 时间：TerrainData.SetAlphamaps 峰值应显著下降。
  • 场景内拖拽控制点和执行 Transform 时，预览网格保持可见。

准备就绪：可在项目中进行实际验证。
